
## 참고: 더 좋았을 요청 예시 (대화 중 제안)

처음 Streamlit 앱을 만들 때, 아래처럼 요청했으면 데이터·차트까지 한 번에 구현할 수 있었습니다.

```
app.py로 Streamlit 주식 분석 앱을 만들어 줘.

- 제목: "주식 데이터 분석기"
- 종목 코드 입력 (기본값: 005930.KS)
- 기간 선택: 1개월, 3개월, 6개월, 1년
- "데이터 조회" 버튼
- yfinance로 데이터 가져오기

조회 성공 시 화면에 아래를 표시해 줘:
- 완료 메시지
- 회사명
- 현재가
- 전일 대비 등락률
- 선택한 기간의 종가 차트
- 역사적 데이터 테이블 (OHLCV)

가상환경에서 실행해 줘.
```
