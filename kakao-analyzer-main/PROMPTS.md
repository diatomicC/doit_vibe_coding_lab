# 카카오톡 대화 분석기 — 요청 프롬프트 정리

## 1. 초기 앱 생성

### 1-1. Streamlit 기본 앱
**참고 파일:** `KakaoTalk_Chat_동생_2026-06-11-20-08-39.csv`

```
@KakaoTalk_Chat_동생_2026-06-11-20-08-39.csv Streamlit으로 카카오톡 대화 분석기를 만들어 줘. 이건 예시 csv 파일이야. 
app.py 파일을 만들어서 작성해 줘.

기본 기능:
- CSV 파일 업로드 기능
- 파일을 업로드하면 pandas로 불러오기
- Date, User, Message 칼럼이 있는 구조야.
- 불러온 데이터 미리보기(처음 10개 행)
- 전체 메시지 개수 표시
- 대화 참여자 목록 표시
```

## 2. 분석 기능 추가

### 2-1. 참여자별 통계
**참고 파일:** `KakaoTalk_Chat_동생_2026-06-11-20-25-53.csv`

```
@KakaoTalk_Chat_동생_2026-06-11-20-25-53.csv app.py에 참여자별 통계 기능을 추가해 줘.

- 참여자별 메시지 개수(막대그래프로 시각화)
- 참여자별 총 글자 수
- 참여자별 평균 메시지 길이
- 가장 긴 메시지를 보낸 사람과 그 메시지 내용

plotly로 예쁜 차트를 만들어 줘.
```

### 2-2. 시간대별 분석

```
app.py에 시간대별 분석 기능을 추가해 줘.
- 시간대별(0시~23시) 메시지 분포(막대그래프)
- 요일별 메시지 분포(월~일, 한글로 표시)
- 월별 메시지 추이(선 그래프)
- 대화가 가장 활발한 시간대 표시
- 대화가 가장 활발한 요일 표시
Date 칼럼을 datetime으로 파싱해서 분석해 줘.
plotly로 인터랙티브한 차트를 만들어 줘.
```

### 2-3. 단어 분석

```
@KakaoTalk_Chat_동생_2026-06-11-20-25-53.csv app.py에 자주 쓰는 단어 분석 기능을 추가해 줘.

- 전체 메시지에서 가장 많이 쓴 단어 TOP 20(막대그래프)
- 참여자별로 가장 많이 쓴 단어 TOP 10
- 워드클라우드 이미지 생성해서 표시
- "ㅋ" 포함된 메시지 횟수 비교(ㅋㅋ, ㅋㅋㅋ 등)
- "ㅎ" 포함된 메시지 횟수 비교

분석할 때 다음은 제외해 줘:
- 1글자 단어
- "사진", "이모티콘", "동영상", "보이스톡" 같은 시스템 메시지
- URL 링크
- 숫자만 있는 메시지(통화 시간 등)

한글 워드클라우드를 위해 한글 폰트 경로 설정도 해줘.
Windows면 malgun.ttf, Mac이면 AppleGothic 사용해 줘.
```

### 2-4. 답장 속도 분석

```
@KakaoTalk_Chat_동생_2026-06-11-20-25-53.csv app.py에 답장 속도 분석 기능을 추가해 줘.

- 상대방 메시지 이후 내가 답장하기까지 걸린 평균 시간
- 참여자별 평균 답장 속도 비교
- 가장 빠른 답장 TOP 5(몇 초 만에 답했는지)
- 1시간 이상 답장하지 않은 횟수(읽씹 카운트)

단, 같은 사람이 연속으로 보낸 메시지는 제외하고,
새로운 대화 시작(6시간 이상 공백)은 답장 시간 계산에서 제외해 줘.
```

## 3. UI/UX 개선

### 3-1. 탭 구조로 전환

```
app.py를 탭 구조로 바꿔 줘. 
탭 구성: 
1. 기본 통계: 전체 메시지 수, 참여자별 메시지 개수, 평균 길이 
2. 시간 분석: 시간대별, 요일별, 월별 차트 
3. 단어 분석: 자주 쓰는 단어, 워드클라우드 
4. 답장 속도: 평균 답장 시간, 읽고 답장하지 않는 메시지 카운트 st.tabs()를 사용해서 구현해 줘.
각 탭에 이모지도 넣어서 보기 좋게 만들어 줘.
```

### 3-2. 사이드바 추가

```
@KakaoTalk_Chat_동생_2026-06-11-20-25-53.csv app.py에 사이드바를 추가해 줘.

사이드바에 들어갈 내용:
- 앱 제목과 간단한 설명
- CSV 파일 업로드 버튼
- 파일이 업로드되면 기본 정보 표시(메시지 수, 참여자 이름, 기간)
- 사용 방법 안내 텍스트

메인 화면에는 탭과 분석 결과만 표시해 줘.
```

### 3-3. 기본 통계 탭 대시보드 스타일

```
@KakaoTalk_Chat_동생_2026-06-11-20-25-53.csv app.py의 기본 통계 탭을 대시보드 스타일로 꾸며 줘.

- st.metric()을 사용해서 주요 숫자를 카드 형태로 표시
- 전체 메시지 수, 대화 기간, 일평균 메시지 수 등
- st.columns()로 가로로 나란히 배치
- 참여자별 통계도 깔끔한 카드 형태로

색상도 적절히 사용해서 보기 좋게 만들어 줘.
```

### 3-4. 탭 호버 색상 변경

```
