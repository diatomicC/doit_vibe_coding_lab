## 1. 지도 화면 기본 UI

**파일:** `lib/main.dart`

```text
main.dart 파일을 수정해서 지도 화면을 만들어 줘.
- 전체 화면에 Google Maps를 표시
- 화면 하단에 두 개의 버튼 추가:
 1. "+" 버튼 (왼쪽): 사진 데이터 불러오기용
 2. ">" 버튼 (오른쪽): 애니메이션 화면 이동용
- 지도는 한국을 기본 위치로 설정
- 버튼들은 하단에 고정되어 있고,
 + 버튼은 초록색 배경, > 버튼은 파란색 배경으로 만들어 줘
```

## 6. `+` 버튼 — 사진/GPS/지도 연동

**관련:** 갤러리 권한, EXIF, `PhotoLocation`, 마커, 폴리라인, Haversine

```text
+ 버튼을 눌렀을 때 다음과 같이 작동하도록 해줘.:
갤러리 접근 권한 확인 및 요청
날짜 범위 선택 다이얼로그(시작일~종료일, 기본값 최근 1개월)

갤러리에서 여러 장 사진 선택
각 사진의 EXIF 데이터에서 GPS 좌표(위도/경도)와 촬영 날짜 추출
GPS 위치 정보 없는 사진은 자동 제외

추출된 데이터를 PhotoLocation 클래스로 저장하고 날짜순 정렬

지도에 빨간색 마커 표시(탭하면 촬영 날짜 표시)
마커들을 시간순으로 파란색 선(두께 5)으로 연결

첫 번째 사진 위치로 카메라 이동, 모든 마커가 보이도록 경계 자동 조정
Haversine 공식으로 총 이동 거리 계산 후 콘솔 출력

필요한 패키지가 있으면 자동으로 설치하고, 안드로이드 권한 설정도 필요하면 알려 줘.
각 단계를 함수로 분리해서 깔끔하게 작성해 줘.
```

## 7. 타임라인 화면 생성

**파일:** `lib/screens/timeline_screen.dart`

```text
lib/screens/timeline_screen.dart 파일을 만들어 줘.
photoLocations를 받아서:
- 날짜별로 그룹화
- 50m 이내는 같은 장소로 묶기
- 각 장소마다 카드로 표시(시간, 주소, 사진 섬네일, 머문 시간)
- 역지오코딩으로 주소 표시
- 하단에 통계(거리, 장소수, 사진 수)
- 섬네일 탭하면 확대
- 장소 탭하면 위치 정보 반환하고 pop
필요한 패키지 설치하고, Material Design으로 깔끔하게
```

## 8. `>` 버튼 — 타임라인 연동

**파일:** `lib/main.dart` ↔ `timeline_screen.dart`

```text
main.dart의 > 버튼 눌렀을 때:
- timeline_screen으로 이동
- photoLocations 전달
- 슬라이드 애니메이션
- pop 받으면 해당 위치로 카메라 이동
```
