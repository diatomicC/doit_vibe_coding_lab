# AI 가계부 프로젝트 — 요청 프롬프트 정리

---

## 1. 기본 가계부 UI

```
이 페이지를 간단한 가계부 웹 사이트로 바꿔 줘.
 - 상단에 "나의 AI 가계부" 제목
 - 중앙에 지출 내역을 입력할 수 있는 입력 창
 - "날짜", "금액", "내용" 입력 필드
 - "저장하기" 버튼
 - 깔끔하고 모던한 디자인으로 만들어 줘.
```

---

## 2. Supabase 테이블 생성

```
Supabase에서 사용할 expenses 테이블을 만드는 SQL 쿼리를 작성해줘.
필요한 컬럼:
- id(자동 생성되는 고유 번호)
- created_at(생성 시간)
- date(지출 날짜, text 타입)
- amount(지출 금액, 정수)
- description(지출 내용, text 타입)
```

---

## 3. Supabase 연동

```
아까 만든 Supabase expenses 테이블과 웹 사이트를 연결해 줘.
- .env.local 파일에 이미 Supabase URL과 API Key 설정해 놨어
- 저장 버튼을 누르면 expenses 테이블에 데이터 추가
- 페이지를 로드하면 Supabase에서 기존 데이터를 불러와서 카드 형태로 표시
- 최신 데이터가 위에 오도록 정렬
- 저장 후에는 입력 창 비우기
```

---

## 4. 반응형 디자인

```
모바일에서도 사용하기 편하도록 반응형으로 만들어 줘.
- 모바일에서는 글씨 크기를 더 크게
- 버튼을 손가락으로 누르기 쉽게 크게
- 입력 창 간격을 넓게
- 화면 너비에 맞게 자동 조절되도록
```

---

## 5. 미니멀 디자인 개선

```
디자인을 노션이나 애플 스타일처럼 미니멀하고 세련되게 개선해 줘.
- 배경은 심플한 흰색 또는 아주 연한 회색
- 불필요한 테두리 제거하고 여백으로 구분
- 입력 영역과 카드는 subtle한 배경색 차이로 구분(진한 그림자 X)
- 버튼은 flat하고 심플하게, hover 시 살짝 어두워지는 정도
- 타이포그래피 중심으로 하고 금액은 숫자 폰트로 크고 명확하게
- 전체적으로 공간감 있게, 답답하지 않게
- 색상은 최소한으로, 강조 색은 하나만 사용
```

## 7. AI 챗봇 UI 리디자인

```
가계부를 AI 챗봇 인터페이스로 완전히 리디자인해 줘.
필요한 라이브러리:
- @google/generative-ai 설치(Gemini API 사용)
 - 환경 변수 GEMINI_API_KEY는 .env.local에 이미 설정되어 있어.
UI 요구 사항:
- 카카오톡 같은 대화형 인터페이스
 - 상단에 제목 "AI 가계부 챗봇"
 - 중앙에 대화 메시지들이 표시되는 영역(스크롤 가능)
 - 하단에 메시지 입력 창과 전송 버튼
 - 사용자 메시지는 오른쪽, AI 응답은 왼쪽
 - 기존 입력 폼(날짜/금액/내용)은 모두 제거
저장된 지출 내역 표시:
 - 대화 창 위에 저장된 지출 내역을 카드 형태로 표시
 - 날짜, 금액, 내용이 한눈에 보이게
 - 최신 것이 위에 오도록
디자인:
 - 미니멀하고 깔끔하게
 - 모바일에서도 사용하기 편하게
 - 채팅 말풍선 스타일
```

## 8. Gemini API 연동

```
Gemini API를 연결해서 챗봇이 작동하도록 해줘.
 
API 엔드포인트 생성:
- app/api/chat/route.ts 파일 생성
- Gemini API 호출 로직 작성
- 환경 변수 GEMINI_API_KEY 사용
 
AI 기능 정의:
1. 사용자가 지출 내용을 자연어로 입력(예: "오늘 점심 15000원")
2. Gemini가 메시지를 분석해서 날짜, 금액, 내용 추출
3. 추출한 정보를 JSON 형태로 반환 { date, amount, description }
4. Supabase expenses 테이블에 자동 저장
5. 사용자에게 확인 메시지 전송
 
예시 대화:
사용자: "어제 택시 탔는데 2만 원 나왔어."
AI 분석: { date: "2024-12-29", amount: 20000, description: "택시" }
AI 응답: "12월 29일 택시 20,000원을 저장했어요!"

오류 처리:
- 날짜나 금액을 파악할 수 없으면 다시 물어보기
- API 오류 발생 시 사용자에게 안내
.env.local에 GEMINI_API_KEY가 이미 설정되어 있어.
```

## 9. 통계 질문 기능

```
챗봇에 통계 질문 기능을 추가해 줘.
사용자가 질문하면:
1. Supabase에서 기존 지출 데이터를 모두 가져와.
2. Gemini에게 데이터와 질문을 함께 전달
3. Gemini가 데이터를 분석해서 답변

예시 질문:
- "이번 달 총 지출이 얼마야?"
- "가장 많이 쓴 항목이 뭐야?"
- "어제 뭐 샀더라?"
- "지난주에 얼마 썼어?"
- "식비로 얼마나 쓰고 있어?"

지출 입력과 질문을 구분:
- 금액이 포함되어 있으면 → 지출 입력
- "얼마", "뭐", "어떻게" 같은 의문사 → 질문
질문 응답은 자연스럽고 친근하게
```
